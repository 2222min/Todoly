# PO 응답 + 대표 승인 — v6

## PO 응답

### 이슈 1~3: 카테고리 기능
기획안 3.9에 이미 정의된 기능들이 구현 누락. 추가 기획 불필요, 즉시 반영.

#### 카테고리 추가 바텀시트 구성
- 이름 입력 필드
- 색상 선택 (8색 팔레트: 빨강/주황/노랑/초록/파랑/남색/보라/회색)
- 이모지 선택 (자주 쓰는 10개 프리셋)
- 추가 버튼

#### 카테고리별 필터 화면
- 기존 메인 리스트와 동일 구조
- 헤더에 카테고리 이름 + 색상 표시
- 해당 카테고리의 할 일만 표시
- 뒤로가기 → 카테고리 관리 화면 복귀

#### 카테고리 수정/삭제
- iOS 기본 confirmationDialog 사용 (별도 디자인 불필요)
- "수정" → 추가 바텀시트와 동일 UI (기존 값 채워진 상태)
- "삭제" → 삭제 확인 다이얼로그
