## 이슈 1: 할 일 수정 기능 미구현

### 현상
- 카드의 ✎ 수정 버튼을 탭해도 아무 반응 없음
- TaskDetailView(상세 화면)가 존재하지만 진입 경로가 없음

### 요청
- 카드 ✎ 버튼 탭 → TaskDetailView로 이동 (기존 데이터 바인딩)
- 카드 자체를 탭해도 상세 화면으로 이동 가능하도록

---

## 이슈 2: 할 일 추가 시 상세 옵션 없음

### 현상
- Quick Add 바에서 텍스트만 입력 가능
- 알림, 마감일, 우선순위, 카테고리 설정 불가
- 기획안 2.1에 "방법 2: 상세 추가" 정의되어 있으나 구현 안 됨

### 요청
Quick Add 바를 탭하면 상세 추가 화면(바텀시트)이 올라오도록 변경:
- 제목 입력 (필수)
- 마감일 선택 (Date Picker)
- 알림 설정 (프리셋 칩)
- 우선순위 선택 (High/Medium/Low 칩)
- 카테고리 선택 (칩)
- 추가 버튼

기존 Quick Add의 "텍스트 입력 후 엔터" 빠른 추가도 유지.
