## 1. 프로젝트 개요

### 1.1 비전
> "최소한의 인터랙션으로 최대한의 정보 전달"

심플하고 직관적인 iOS TODO 관리 앱. 빠른 할 일 추가, 한눈에 파악 가능한 상태 표시, 깔끔한 정보 계층 구조를 핵심 가치로 합니다.

### 1.2 타겟 유저
- 20~40대 직장인 및 학생
- 복잡한 프로젝트 관리 도구보다 가벼운 TODO 앱을 원하는 사용자

## 2. 핵심 기능 정의

### 2.1 할 일 추가

#### 방법 1: 인라인 빠른 추가 (Quick Add)
| 항목 | 설명 |
|------|------|
| 위치 | 메인 화면 상단 상시 노출 |
| 동작 | 제목 입력 → 엔터 또는 추가 버튼 탭 → 즉시 추가 |
| 기본값 | 우선순위: 중간, 카테고리: 없음, 마감일: nil (마감일 없음) |

#### 방법 2: 상세 추가 (AddTaskSheet)
| 항목 | 설명 |
|------|------|
| 진입 | 플로팅 버튼(+) 또는 인라인 입력 옆 상세 버튼 |
| 제목 | 필수 입력 |
| 메모 | 선택 입력 (멀티라인) |
| 마감일 | 선택 (Date Picker), 기본값: hasDueDate = false (마감일 없음) |
| 우선순위 | 높음 🔴 / 중간 🟠 / 낮음 🔵 |
| 카테고리 | 선택 (가로 스크롤 칩) |

### 2.2 할 일 목록

| 기능 | 설명 |
|------|------|
| 섹션 분리 | 미완료 항목 상단, 완료 항목 하단 (접기/펼치기) |
| 필터링 | 완료 / 미완료 |
| 정렬 | 우선순위별 / 마감일순 |
| 검색 | 상단 검색바 (돋보기 아이콘 탭 시 확장), 제목 + 메모 내용 검색 |

### 2.3 할 일 완료 처리

| 동작 | 결과 |
|------|------|
| 체크박스 탭 | 완료 처리 (할일 탭, 캘린더 모두 동일) |
| 완료 표시 | 취소선 + 투명도 55% + "완료됨" 섹션으로 이동 |
| 완료 시간 | completedAt 시간 표시 ("오전 8:00 완료" 형식, 캘린더·할일 탭 모두 적용) |
| 체크박스 | TodoCheckbox 공통 컴포넌트 사용 — 미완료: 빈 원 스트로크, 완료: 녹색(#34C759) filled + 체크마크, 히트 영역 44x44 |

### 2.4 할 일 삭제

| 동작 | 결과 |
|------|------|
| 스와이프 삭제 | "삭제 취소" Undo 토스트 3초간 표시 |
| 휴지통 | 최근 30일 삭제 항목 보관, 복원 가능 |
| 자동 삭제 | 30일 경과 시 영구 삭제 |

### 2.5 카테고리

| 항목 | 설명 |
|------|------|
| 기본 카테고리 | 개인, 업무, 쇼핑, 기타 |
| 커스텀 | 사용자 추가/수정/삭제 가능 |
| 색상 | 카테고리별 색상 지정 |
| 아이콘 | 이모지 48개 (6그룹: 일상&생활, 업무&학습, 건강&운동, 취미&여가, 쇼핑&금융, 소셜&관계), 섹션별 라벨 표시 |

### 2.6 우선순위 시각화

리스트 아이템 좌측에 컬러 인디케이터 바 표시:

| 우선순위 | 색상 | HEX |
|----------|------|-----|
| 높음 | 🔴 빨간색 | #FF3B30 |
| 중간 | 🟠 주황색 | #FF9500 |
| 낮음 | 🔵 파란색 | #007AFF |
| 없음 | — | 인디케이터 숨김 |

### 2.7 마감일 표시 시스템

| 조건 | 표시 | 스타일 |
|------|------|--------|
| 마감 지남 | "지연" 배지 | 빨간색 배지 + 아이템 배경 연한 빨강 |
| 오늘 마감 | "오늘" 배지 | 주황색 배지 |
| 내일 마감 | "내일" 배지 | 노란색 배지 |
| 7일 이내 | "D-N" 텍스트 | 회색 텍스트 |
| 7일 초과 | 날짜 표시 | 회색 텍스트 |

## 추가 기능: 캘린더 뷰 & 디자인 개선 (변경: 2026-04-26)

### 캘린더 뷰 기능

하단 탭에 캘린더 탭을 추가하여 날짜 기반으로 할 일을 조회할 수 있다.

| 항목 | 설명 |
|------|------|
| 탭 위치 | Tasks 다음, Categories 앞 (두 번째 탭) |
| 캘린더 형태 | 월간 캘린더 그리드 (7열, 일~토) |
| 월 이동 | 좌/우 화살표로 이전/다음 월 이동 (슬라이드 트랜지션) |
| Dot Indicator | 날짜별 할 일 우선순위 색상 점 최대 3개 표시 |
| 날짜 선택 | 날짜 탭 시 하단에 해당 날짜 할 일 목록 슬라이드 인 |
| 완료 체크 | 체크박스 탭으로 완료/미완료 처리 (스와이프 완료 제거, 체크박스만 사용) |
| 완료 시간 | completedAt 시간 표시 ("오전 8:00 완료" 형식) |
| 완료 항목 UI | 미완료와 동일한 카드 UI (체크박스 on/off + 색상 처리 + 투명도 0.55), DayTaskRow 통일 구조 |
| 체크박스 | TodoCheckbox 공통 컴포넌트 (미완료: 빈 원 스트로크, 완료: 녹색 #34C759 filled + 체크마크, 히트 영역 44x44) |
| 데이터 연동 | TodoStore 실시간 반영 |
| 빈 상태 | "이 날은 할 일이 없어요 🎉" / "마감일을 설정하면 캘린더에서 확인할 수 있어요 📅" |

#### 캘린더 완료 항목 표시 정책 (변경: 2026-04-26)

| 조건 | 표시 기준 |
|------|----------|
| dueDate 있는 완료 할일 | dueDate 기준 표시 (기존과 동일) |
| dueDate 없는 완료 할일 | completedAt 기준 표시 (히스토리 확인용) |

#### 캘린더 "날짜 미지정" 섹션 — B안 채택 (변경: 2026-04-26)

캘린더 하단에 "📌 날짜 미지정" 접이식 섹션을 추가한다.

| 항목 | 설명 |
|------|------|
| 위치 | 캘린더 하단 (날짜별 할 일 목록 아래) |
| 대상 | dueDate가 nil인 미완료 할일 |
| 표시 조건 | 날짜 선택과 무관하게 항상 표시 |
| 접기/펼치기 | 가능 (기본 펼침) |

**라이프사이클:**
- 진입: 생성 시 dueDate nil / 수정으로 dueDate 제거
- 빠짐: 날짜 지정 → 해당 날짜로 이동 / 완료 → completedAt 날짜의 완료됨에 표시 / 삭제 → 휴지통

## 추가 화면 설계 (v3 — 디자인팀 요청, 대표 승인)

### 3.7 스플래시 화면
- 앱 실행 시 1.5초 표시
- 브랜드 그라데이션 배경 + "Todoly ✨" 로고 중앙

### 3.8 로그인 화면
- "Todoly" 로고 + 서브 메시지
- Apple로 계속하기 / Google로 계속하기 / 이메일로 계속하기
- 이용약관 및 개인정보처리방침 동의 안내

### 3.9 카테고리 관리 화면
- 카테고리 목록: 색상 원형 + 이름 + 할 일 수 + 더보기(⋯)
- 더보기 탭 → 수정/삭제 액션시트
- 추가(+) 탭 → 이름 + 색상 선택 바텀시트
- 카테고리 탭 → 해당 카테고리 필터링된 메인 리스트

### 3.10 검색 화면
- 검색바 자동 포커스 + 실시간 검색
- 최근 검색어 (최대 5개, 삭제 가능)
- 검색 결과: 일반 리스트 아이템과 동일 형태
- 검색어 하이라이트 표시

### 3.11 Undo 토스트
- 위치: 화면 하단 (Bottom Nav 위)
- 다크 그레이 배경 + "되돌리기" 버튼
- 3초 타이머 프로그레스 바

### 3.12 스와이프 삭제 인터랙션
- 좌측 스와이프 → 빨간 삭제 영역 노출
- 삭제 실행 → Undo 토스트 표시

### 3.13 삭제 확인 다이얼로그
- 딤 배경 + 중앙 카드
- "정말 삭제하시겠습니까?" + 취소/삭제 버튼
- 사용처: 휴지통 전체 삭제, 개별 영구 삭제

### 3.14 알림 설정 화면 (iOS 리마인더 스타일)

할 일 상세 화면에서 🔔 아이콘 탭 시 알림 설정 바텀시트 표시.
iOS 기본 알람 앱과 동일한 UX 패턴 적용.

#### 알림 설정 옵션
| 옵션 | 설명 |
|------|------|
| 알림 없음 | 기본값 |
| 정시 알림 | 마감일 당일 지정 시간에 알림 |
| 사전 알림 | 마감일 N분/시간/일 전 알림 |
| 반복 알림 | 매일/매주/매월 반복 (v1.1) |
| 커스텀 | 날짜 + 시간 직접 지정 |

#### 사전 알림 프리셋
- 5분 전 / 15분 전 / 30분 전 / 1시간 전 / 1일 전 / 2일 전

#### 알림 동작
- iOS UNUserNotificationCenter 사용
- 알림 탭 → 앱 실행 → 해당 할 일 상세 화면으로 이동
- 알림 배너: "Todoly 📋 [할 일 제목] - [마감까지 N시간]"
- 알림 사운드: iOS 기본 사운드 또는 커스텀
