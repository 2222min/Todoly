## 추가 화면 기획

### A. 스플래시 / 온보딩 / 로그인

#### A-1. 스플래시 화면
```
┌──────────────────────────────────┐
│                                  │
│                                  │
│                                  │
│           Todoly ✨               │
│      (로고 + 앱 이름)             │
│                                  │
│                                  │
│                                  │
└──────────────────────────────────┘
```
- 앱 실행 시 1.5초간 표시
- 배경: 따뜻한 그라데이션 (브랜드 컬러)
- 로고 + "Todoly" 텍스트 중앙 배치

#### A-2. 온보딩 (3장 슬라이드)
```
┌──────────────────────────────────┐
│                                  │
│        (일러스트)                 │
│                                  │
│    "빠르게 할 일을 추가하세요"     │
│    "한 줄 입력으로 즉시 추가"      │
│                                  │
│         ● ○ ○                    │  페이지 인디케이터
│                                  │
│      [ 다음 ]  [ 건너뛰기 ]       │
└──────────────────────────────────┘
```
- 슬라이드 1: 빠른 추가 소개
- 슬라이드 2: 우선순위 & 마감일 관리 소개
- 슬라이드 3: 카테고리 정리 소개
- 마지막 슬라이드: "시작하기" 버튼

#### A-3. 로그인 화면
```
┌──────────────────────────────────┐

```

### B. 카테고리 관리 화면
```
┌──────────────────────────────────┐
│  ←  카테고리 관리           ＋   │
├──────────────────────────────────┤
│                                  │
│  🔵  개인          3개 할 일  ⋯  │  색상 + 이름 + 할 일 수 + 더보기
│  🟢  업무          5개 할 일  ⋯  │
│  🟡  쇼핑          1개 할 일  ⋯  │
│  ⚪  기타          0개 할 일  ⋯  │
│                                  │
│  ─────────────────────────────   │
│                                  │
│  💡 카테고리를 탭하면              │
│     해당 카테고리의 할 일만        │
│     볼 수 있어요                  │
│                                  │
└──────────────────────────────────┘
```
- 더보기(⋯) 탭 시: 수정 / 삭제 액션시트
- 카테고리 추가(+) 탭 시: 이름 + 색상 선택 바텀시트
- 카테고리 탭 시: 해당 카테고리 할 일만 필터링된 메인 리스트로 이동

### C. 검색 화면
```
┌──────────────────────────────────┐
│  ←  [ 검색어를 입력하세요...  ✕ ]│  검색바 (자동 포커스)
├──────────────────────────────────┤
│                                  │
│  최근 검색어                      │
│  보고서  ✕ │ 장보기  ✕ │ 운동  ✕ │
│                                  │
│  ─── 검색 결과 입력 후 ───        │
│                                  │
│  🔴│ ☐  프로젝트 보고서 작성      │  일반 리스트 아이템과 동일
│     │     업무 · 지연 🔴          │
│                                  │
│  검색어 하이라이트 표시            │
│                                  │
└──────────────────────────────────┘
```
- 검색 아이콘 탭 → 검색 화면 전환 (자동 키보드)
- 실시간 검색 (타이핑 시 즉시 결과)
- 제목 + 메모 내용 검색
- 검색어 하이라이트 (볼드 또는 배경색)
- 최근 검색어 최대 5개 저장

### D. 인터랙션 UI 컴포넌트

#### D-1. Undo 토스트
```
┌──────────────────────────────────┐
│                                  │
│  ┌────────────────────────────┐  │
│  │ 🗑 "운동하기" 삭제됨  [되돌리기]│  │  하단 토스트 (3초)
```
