## 이슈 목록

### 이슈 1: 카테고리 "+" 버튼 동작 없음
- 카테고리 관리 화면의 + 버튼 탭 시 아무 반응 없음
- 기획안 3.9에 "추가(+) 탭 → 이름 + 색상 선택 바텀시트" 정의되어 있으나 미구현
- **필요**: 카테고리 추가 바텀시트 (이름 입력 + 색상 선택 + 이모지 선택)

### 이슈 2: 카테고리별 할 일 목록 확인 불가
- 기획안 3.9에 "카테고리 탭 → 해당 카테고리 필터링된 메인 리스트" 정의됨
- 현재 카테고리를 탭해도 아무 반응 없음
- **필요**: 카테고리 탭 → 해당 카테고리의 할 일만 필터링된 리스트 화면

### 이슈 3: 카테고리 "⋯" 더보기 버튼 동작 없음
- 기획안 3.9에 "더보기 탭 → 수정/삭제 액션시트" 정의됨
- 현재 탭해도 아무 반응 없음
- **필요**: 더보기 → 수정/삭제 액션시트 (confirmationDialog)

### 이슈 4: Due Date 커스텀 UI (풀페이지)
- 현재 iOS 시스템 DatePicker 사용 중 (compact 스타일)
- 대표 요청: 시스템 UI 대신 커스텀 날짜/시간 선택 UI
- 바텀시트가 아닌 **풀페이지**로 표시
- **필요 화면**: 커스텀 Date/Time Picker 풀페이지
  - 캘린더 뷰 (월간)
  - 시간 선택 (스크롤 휠 또는 그리드)
  - v5 스타일 가이드에 맞는 따뜻한 디자인
