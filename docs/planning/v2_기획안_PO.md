## 1. 프로젝트 개요

### 1.1 앱 이름
**Todoly** - 심플하고 직관적인 TODO 관리 앱

### 1.2 목표
- 최소한의 인터랙션으로 최대한의 정보 전달
- 빠른 할 일 추가, 직관적인 상태 파악
- 깔끔하고 계층적인 정보 구조

### 1.3 타겟 유저
- 20~40대 직장인 및 학생
- 가벼운 TODO 관리를 원하는 사용자

## 2. 핵심 기능

### 2.1 할 일 추가 (✅ v1 피드백 #1 반영)
**방법 1: 인라인 빠른 추가**
- 메인 화면 상단에 텍스트 입력 필드 상시 노출
- 제목 입력 후 엔터(또는 추가 버튼)로 즉시 추가
- 기본값: 우선순위 중간, 카테고리 없음, 마감일 없음

**방법 2: 상세 추가**
- 플로팅 버튼(+) 또는 인라인 입력 옆 상세 버튼
- 제목 입력 (필수)
- 메모 입력 (선택)
- 마감일 설정 (선택, Date Picker)
- 우선순위 설정 (높음🔴/중간🟠/낮음🔵)
- 카테고리 선택

### 2.2 할 일 목록
- 전체 할 일 리스트 표시
- **미완료 항목 상단, 완료 항목 하단 분리** (✅ 피드백 #8 반영)
- 완료/미완료 필터링
- 우선순위별 / 마감일순 정렬
- **🔍 검색 기능** (✅ 피드백 #3 반영)
  - 상단 검색바 (돋보기 아이콘 탭 시 확장)
  - 제목 + 메모 내용 검색

### 2.3 할 일 완료/삭제 (✅ 피드백 #2 반영)
- 체크박스 탭으로 완료 처리
- 완료 시: **취소선 + 투명도 50% + 하단 "완료됨" 섹션으로 이동** (✅ 피드백 #8 반영)
- 스와이프 삭제 시 **"삭제 취소" Undo 토스트** 3초간 표시
- **휴지통 기능**: 최근 30일 삭제 항목 보관, 복원 가능

### 2.4 카테고리
- 기본 카테고리: 개인, 업무, 쇼핑, 기타
- 사용자 커스텀 카테고리 추가 가능
- 카테고리별 색상 지정

### 2.5 우선순위 시각화 (✅ 피드백 #4 반영)
- 리스트 아이템 좌측에 **컬러 인디케이터 바** 표시
  - 높음: 🔴 빨간색 (#FF3B30)
  - 중간: 🟠 주황색 (#FF9500)
  - 낮음: 🔵 파란색 (#007AFF)
- 우선순위 없음: 인디케이터 숨김

### 2.6 마감일 알림 (✅ 피드백 #5 반영)
- **오늘 마감**: 주황색 배지 "오늘"
- **내일 마감**: 노란색 배지 "내일"
- **마감 지남**: 빨간색 배지 "지연" + 아이템 배경 연한 빨강
- **7일 이내**: 회색 텍스트로 "D-N" 표시

## 3. 화면 구성

### 3.1 메인 화면 (할 일 목록)
```
┌─────────────────────────────┐
│  Todoly          🔍  ≡      │  ← 앱 타이틀 + 검색 + 필터/정렬
├─────────────────────────────┤
│  [ 할 일을 입력하세요...  ＋]│  ← 인라인 빠른 추가
├─────────────────────────────┤
│                             │
│  ■ 미완료 (3)               │
│  🔴│☐ 프로젝트 보고서 작성   │  ← 우선순위 컬러바 + 체크박스
│     │  업무 · 지연 🔴        │  ← 카테고리 + 마감일 배지
│  🟠│☐ 장보기                │
│     │  쇼핑 · 오늘           │
│  🔵│☐ 책 읽기               │
│     │  개인 · D-5            │
│                             │
│  ■ 완료됨 (2)     [접기 ▾]  │  ← 완료 섹션 (접기/펼치기)
│     │☑ 이메일 확인  (50%)    │  ← 투명도 낮춤 + 취소선
│     │☑ 회의 참석    (50%)    │
│                             │
├─────────────────────────────┤
│          [ ＋ ]              │  ← 플로팅 상세 추가 버튼
└─────────────────────────────┘
```

### 3.2 할 일 상세/수정 화면
- 제목 입력 필드
- 메모 입력 필드 (멀티라인)
- 마감일 선택 (Date Picker)
- 우선순위 선택 (컬러 칩 3개)
- 카테고리 선택 (가로 스크롤 칩)
- 저장/취소 버튼

### 3.3 빈 상태 화면 (✅ 피드백 #6 반영)
```
┌─────────────────────────────┐
│                             │
│        📝                   │
│   (일러스트: 체크리스트)      │
│                             │
│   "오늘 할 일을 추가해보세요" │
│   "작은 것부터 시작하면       │
│    큰 일도 해낼 수 있어요!"   │
│                             │
│      [ 첫 할 일 추가하기 ]   │
│                             │
└─────────────────────────────┘
```

### 3.4 카테고리 관리 화면
- 카테고리 목록 (색상 원형 + 이름)
- 추가/수정/삭제 기능

### 3.5 휴지통 화면
- 최근 삭제된 항목 목록
- 복원 / 영구 삭제 버튼
- 30일 후 자동 삭제 안내

### 3.6 리스트 아이템 정보 계층 (✅ 피드백 #7 반영)
```
┌─────────────────────────────┐
│ 🔴│ ☐  프로젝트 보고서 작성  │  ← 1차 정보: 우선순위 컬러 + 체크박스 + 제목
│   │     업무 · 지연 🔴       │  ← 2차 정보: 카테고리 + 마감일 (작은 폰트, 회색)
└─────────────────────────────┘
```
- **1차 정보** (즉시 인지): 우선순위 컬러바, 체크박스, 제목 (16pt, Bold)
- **2차 정보** (필요 시 확인): 카테고리, 마감일 배지 (12pt, Gray)

## 4. 기술 요구사항

### 4.1 클라이언트 (iOS)
- Swift / SwiftUI
- 최소 지원 버전: iOS 16+
- 로컬 데이터 저장: SwiftData
- 푸시 알림: 마감일 리마인더

### 4.2 서버
- RESTful API
- 사용자 인증 (이메일/소셜 로그인: Apple, Google)
- 데이터 동기화 (클라우드 백업)
- 휴지통 데이터 30일 보관 후 자동 삭제

### 4.3 데이터 모델
```
User {
  id: UUID
  email: String
  name: String
  createdAt: DateTime
}

Todo {
  id: UUID
  title: String
  memo: String?
  dueDate: DateTime?
  priority: Enum(high, medium, low, none)
  categoryId: UUID?
  isCompleted: Boolean
  completedAt: DateTime?
  isDeleted: Boolean        // 휴지통 지원
  deletedAt: DateTime?      // 30일 후 자동 삭제용
  createdAt: DateTime
  updatedAt: DateTime
  userId: UUID
}

Category {
  id: UUID
  name: String
  color: String (hex)
  userId: UUID
  createdAt: DateTime
}
```
