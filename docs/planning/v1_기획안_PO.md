## 작성자: PO (Product Owner)

## 상태: 대표 리뷰 대기

---

## 1. 프로젝트 개요

### 1.1 앱 이름
**Todoly** - 심플하고 직관적인 TODO 관리 앱

### 1.2 목표
- 사용자가 일상의 할 일을 빠르고 쉽게 관리할 수 있는 iOS 앱
- 최소한의 터치로 할 일 추가/완료/삭제 가능
- 깔끔하고 직관적인 UI/UX

### 1.3 타겟 유저
- 20~40대 직장인 및 학생
- 복잡한 프로젝트 관리 도구보다 가벼운 TODO 앱을 원하는 사용자

---

## 2. 핵심 기능

### 2.1 할 일 추가
- 하단 플로팅 버튼(+)으로 빠른 추가
- 제목 입력 (필수)
- 메모 입력 (선택)
- 마감일 설정 (선택)
- 우선순위 설정 (높음/중간/낮음)

### 2.2 할 일 목록
- 전체 할 일 리스트 표시
- 완료/미완료 필터링
- 우선순위별 정렬
- 마감일순 정렬

### 2.3 할 일 완료/삭제
- 체크박스 탭으로 완료 처리
- 스와이프로 삭제
- 완료된 항목은 취소선 표시

### 2.4 카테고리
- 기본 카테고리: 개인, 업무, 쇼핑, 기타
- 사용자 커스텀 카테고리 추가 가능
- 카테고리별 색상 지정

---

## 3. 화면 구성

### 3.1 메인 화면 (할 일 목록)
- 상단: 앱 타이틀 + 필터/정렬 버튼
- 중앙: 할 일 리스트 (스크롤)
- 하단: 플로팅 추가 버튼(+)

### 3.2 할 일 추가/수정 화면
- 제목 입력 필드
- 메모 입력 필드
- 마감일 선택 (Date Picker)
- 우선순위 선택 (세그먼트 컨트롤)
- 카테고리 선택
- 저장/취소 버튼

### 3.3 카테고리 관리 화면
- 카테고리 목록
- 추가/수정/삭제 기능

## 4. 기술 요구사항

### 4.1 클라이언트 (iOS)
- Swift / SwiftUI
- 최소 지원 버전: iOS 16+
- 로컬 데이터 저장 (Core Data 또는 SwiftData)

### 4.2 서버
- RESTful API
- 사용자 인증 (이메일/소셜 로그인)
- 데이터 동기화 (클라우드 백업)

### 4.3 데이터 모델
- User: id, email, name, createdAt
- Todo: id, title, memo, dueDate, priority, categoryId, isCompleted, createdAt, updatedAt
- Category: id, name, color, userId

---

## 5. 비기능 요구사항
- 앱 실행 시간: 2초 이내
- 오프라인 모드 지원 (로컬 저장 후 온라인 시 동기화)
- 다크모드 지원
