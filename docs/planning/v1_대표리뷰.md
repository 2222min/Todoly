## 수정 요청 사항

### 🔴 사용성 (Usability) 이슈

1. **할 일 추가 플로우가 너무 많은 단계를 요구함**
   - 플로팅 버튼 → 새 화면 전환 → 입력 → 저장 은 3단계
   - 메인 화면에서 바로 텍스트 입력 후 엔터로 추가하는 **인라인 추가** 방식도 지원해야 함
   - 상세 설정(마감일, 우선순위 등)은 추가 후 수정에서 가능하도록

2. **스와이프 삭제만으로는 부족**
   - 실수로 삭제할 수 있음 → **삭제 확인 또는 Undo 기능** 필요
   - 휴지통(최근 삭제) 기능 추가 검토

3. **검색 기능 누락**
   - 할 일이 많아지면 검색이 필수 → 검색 기능 추가 필요

### 🟡 가시성 (Visibility) 이슈

4. **우선순위 표현이 텍스트만으로는 약함**
   - 우선순위별 **컬러 인디케이터** (빨강/주황/파랑) 추가
   - 리스트에서 한눈에 우선순위 파악 가능해야 함

5. **마감일 임박 알림 표시 없음**
   - 오늘/내일 마감인 항목은 **시각적 강조** 필요
   - 마감 지난 항목은 **빨간색 경고** 표시

6. **빈 상태(Empty State) 디자인 누락**
   - 할 일이 없을 때 보여줄 화면 기획 필요
   - 동기부여 메시지 또는 일러스트 추가

### 🟢 가독성 (Readability) 이슈

7. **리스트 아이템 정보 밀도 조절 필요**
   - 제목 + 메모 + 마감일 + 우선순위 + 카테고리를 한 줄에 다 보여주면 복잡
   - **1차 정보**(제목, 체크박스, 우선순위 컬러)와 **2차 정보**(마감일, 카테고리)를 계층적으로 표시

8. **완료된 항목 처리 방식 개선**
   - 취소선만으로는 부족 → **투명도 낮추기 + 하단 분리** 검토
