## 배경
현재 디자인 작업 중 기획안에 정의되어 있으나 디자인이 누락된 화면, 그리고 기획안에 아예 빠져있지만 사용자 플로우상 반드시 필요한 화면/기능을 발견했습니다.

---

## 1. 기획안에 정의되어 있으나 디자인 누락 화면

### 1-1. 카테고리 관리 화면 (기획안 3.4)
- 기획안에 명확히 정의됨: 색상 원형 + 이름 + 더보기(⋯)
- 카테고리 추가/수정/삭제 기능
- **현재 디자인 4개 화면 중 어디에도 없음**
- 필요 이유: Bottom Nav에 "Categories" 탭이 있으므로 반드시 필요

### 1-2. 검색 결과 화면
- 기획안 2.2에 검색 기능 정의됨 (제목 + 메모 내용 검색)
- 검색 아이콘은 헤더에 배치했으나, 검색 결과를 보여주는 화면이 없음
- 필요 이유: 검색 탭 → 결과 표시 → 항목 선택 플로우 필요

---

## 2. 기획안에 빠져있지만 필수적인 화면/기능

### 2-1. 🔴 온보딩 / 로그인 화면
- 기획안 4.2에 "이메일 / Apple 로그인 / Google 로그인" 정의됨
- 그러나 로그인/회원가입 화면 설계가 전혀 없음
- **필수**: 앱 첫 실행 시 사용자가 어떤 화면을 보는지 정의 필요
- 제안:
  - 스플래시 화면 (앱 로고)
  - 온보딩 (1~3장 슬라이드, 앱 소개)
  - 로그인 화면 (Apple/Google/이메일)

### 2-2. 🔴 Undo 토스트 UI
- 기획안 2.4에 "삭제 취소 Undo 토스트 3초간 표시" 정의됨
- 토스트의 위치, 크기, 디자인이 정의되지 않음
- **필수**: 스와이프 삭제 후 즉시 보여야 하는 UI

### 2-3. 🔴 스와이프 삭제 인터랙션
- 기획안 2.4에 "스와이프로 삭제" 정의됨
- 스와이프 시 나타나는 빨간 삭제 영역 디자인 없음
- **필수**: 사용자가 스와이프 가능하다는 것을 인지할 수 있는 어포던스

### 2-4. 🟡 필터/정렬 UI
- 기획안 2.2에 "우선순위별 / 마감일순 정렬" 정의됨
- 헤더의 ≡ 아이콘이 필터/정렬인지, 사이드 메뉴인지 불명확
- 필터/정렬 선택 UI (바텀시트 또는 드롭다운) 필요

### 2-5. 🟡 설정 화면
- 기획안 5에 다크모드, 알림 등 비기능 요구사항 있음
- 사용자가 이를 제어할 설정 화면이 없음
- 제안: 프로필/설정 화면 (알림 on/off, 다크모드, 계정 관리, 로그아웃)

### 2-6. 🟡 삭제 확인 다이얼로그
- 휴지통 "전체 삭제" 시 확인 팝업
- Task Detail "할 일 삭제" 시 확인 팝업
- 실수 방지를 위한 필수 UI
