# 📮 대표 → PO/디자인팀 UI 감성 리뉴얼 요청 (v5)

## 요청일: 2026-04-26
## 요청자: 대표 (시뮬레이터 테스트 후 피드백)

---

## 피드백 원문
> "디자인 구성과 위치는 좋은데, 전체적인 UI 감성이 별로. 너무 딱딱해 보인다."

## 현재 문제 분석

| 요소 | 현재 | 문제 |
|------|------|------|
| 배경색 | #FAF8F3 (차가운 회색빛 크림) | 따뜻함 부족 |
| 주요 버튼/액센트 | #1A1A1A (순수 블랙) | 딱딱하고 차가움 |
| 카드 배경 | 순백 #FFFFFF | 평면적, 감성 없음 |
| 폰트 스타일 | system default | 기계적 느낌 |
| 우선순위 색상 | #FF3B30 / #FF9500 / #007AFF | iOS 시스템 색상 그대로, 개성 없음 |
| 장식 요소 | 없음 | 밋밋함 |
| 전체 톤 | 무채색 + 강한 대비 | 사무적, 차가움 |

## 요청 방향

### 감성 키워드
**따뜻한 · 부드러운 · 아기자기한 · 친근한 · 포근한**

### 구체적 변경 요청

| # | 항목 | 변경 방향 |
|---|------|----------|
| 1 | 배경색 | 따뜻한 크림/피치 톤 (#FFF8F2 계열) |
| 2 | 주요 버튼 | 순수 블랙 → 부드러운 다크 (#2D2D2D) 또는 코랄/라벤더 액센트 |
| 3 | 카드 배경 | 순백 → 연한 피치/라벤더 틴트 또는 미세 그라데이션 |
| 4 | 폰트 | `.rounded` 디자인 적용 (SF Rounded) — 둥글둥글한 느낌 |
| 5 | 우선순위 색상 | 파스텔 톤으로 변경 (#FF6B6B / #FFAB5E / #5B9BF5) |
| 6 | 장식 요소 | 이모지 포인트, 파스텔 도트, 부드러운 그림자 추가 |
| 7 | 그라데이션 | 스플래시/로그인에 따뜻한 파스텔 그라데이션 |
| 8 | 그림자 | 강한 그림자 → 부드럽고 넓은 그림자 (blur 크게, opacity 낮게) |
| 9 | 코너 라운딩 | 20px → 24~28px (더 둥글게) |
| 10 | 인터랙션 | 스프링 애니메이션 (탄성 있는 움직임) |
