## 리뷰어 1: 사용성 전문가 (Usability Expert, 8년차)

### 🔴 Red (반드시 수정)

**R-1. 할일 탭에서 "마감일 없는 할일" 항상 노출은 혼란 유발**
- 오늘 할일만 보여주겠다는 취지와 모순됨
- 마감일 없는 할일이 매일 쌓이면 "오늘 할일" 의미가 퇴색
- **수정안**: 마감일 없는 할일은 별도 "📌 날짜 미지정" 접이식 섹션으로 분리 (캘린더 탭과 동일 패턴)

**R-2. 기간 할일 완료 시 즉시 완료 섹션 이동은 UX 혼란**
- 기간 할일은 내일 다시 미완료로 돌아오는데, 완료 섹션에 넣으면 "삭제된 건가?" 혼동
- **수정안**: 기간 할일은 완료해도 미완료 섹션에 유지하되, 체크 상태 + 투명도 0.55로 표시. 완료 섹션으로 이동하지 않음.

### 🟡 Yellow (개선 권장)

**Y-1. "기간 할일" 용어가 직관적이지 않음**
- 사용자 입장에서 "기간"이 무엇인지 바로 와닿지 않음
- **대안**: "매일 할일", "연속 할일", "루틴" 중 "연속 할일"이 시작~끝 개념을 잘 전달
- 또는 UI에서는 "매일 반복" 라벨로 표시

**Y-2. 기간 할일 진행률 표시 "(3/5)" 가 작은 화면에서 정보 과부하**
- 카테고리 · 기간 · 진행률이 2차 정보 라인에 모두 들어가면 복잡
- **대안**: 진행률은 상세 화면에서만 표시. 카드에서는 "4/28~5/2" + 작은 프로그레스 바(선형)로 대체

## 리뷰어 2: 가시성 전문가 (Visibility Expert, 7년차)

### 🔴 Red (반드시 수정)

**R-3. 오늘 필터 적용 시 "지연된 할일" 처리 정책 불명확**
- dueDate가 어제인 할일: 오늘 탭에 노출해야 하는가?
- 기획안에 "dueDate == 오늘 또는 dueDate < 오늘 (지연)"이라고 했지만, 일주일 전 지연 할일도 계속 보이면 리스트가 오염됨
- **수정안**: 지연 할일은 노출하되, 별도 "⚠️ 지연" 섹션으로 분리하여 시각적 구분. 또는 지연 배지를 강조하여 일반 오늘 할일과 구분.

**R-4. 기간 할일과 일반 할일의 시각적 구분 부족**
- 같은 카드 UI에 기간 표시만 추가하면 사용자가 두 유형을 혼동
- **수정안**: 기간 할일 카드에 좌측 "🔄" 아이콘 또는 반복 표시 아이콘 추가. 또는 카드 상단에 얇은 그라데이션 바로 기간 진행 상태 표시.

### 🟡 Yellow (개선 권장)

**Y-3. 완료 섹션 "오늘 완료" 라벨 명시 필요**
- 기존 "완료됨"에서 "오늘 완료됨"으로 변경하여 필터 적용 사실을 명시
- 사용자가 "내 완료 기록이 사라졌다"고 오해할 수 있음

**Y-4. 기간 할일 종료 후 피드백 없음**
- 5일간 매일 운동하기가 끝나면 아무 피드백 없이 사라짐
- **대안**: 종료일 다음 날 "🎉 연속 할일 완료!" 축하 토스트 또는 완료 섹션에 1일간 표시

## 리뷰어 3: 가독성 전문가 (Readability Expert, 4년차)

### 🔴 Red (반드시 수정)

**R-5. AddTaskSheet "기간 설정" UI가 복잡해질 우려**
- 세그먼트(마감일/기간 설정) + 날짜 피커 2개는 추가 화면에서 인지 부하 증가
- **수정안**: 
  - 기본은 "마감일" 단일 피커 (기존과 동일)
  - "기간으로 설정" 토글을 추가하면 종료일 피커가 나타남
  - 시작일 = 마감일 피커의 날짜, 종료일 = 추가 피커
  - 이렇게 하면 기존 UX를 깨지 않으면서 기간 설정 가능

### 🟡 Yellow (개선 권장)

**Y-5. dailyCompletions 딕셔너리의 데이터 크기 우려**
- 365일 기간 할일이면 365개 엔트리 → UserDefaults 부담
- **대안**: 기간 할일 최대 기간 제한 (예: 90일) 설정 권장

**Y-6. 기간 할일 배지 텍스트 "D-3 남음" 보다 "3일 남음"이 자연스러움**
- 기존 일반 할일의 "D-N" 패턴과 혼동 가능
- 기간 할일은 "N일 남음" 또는 "N일째" 형식이 더 명확
