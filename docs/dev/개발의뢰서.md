## 개발 범위 요약

### 클라이언트 (iOS)
- Swift / SwiftUI / iOS 18+
- UserDefaults + Codable (로컬 영속화)
- UNUserNotificationCenter (알림) + ActivityKit (Live Activity)
- Apple/Google/이메일 인증

### 서버 (v1 경량화)
- Firebase (Spark Plan — 무료)
- Firebase Auth (인증)
- Cloud Firestore (DB + 실시간 동기화 + 오프라인)
- Cloud Functions (휴지통 스케줄러)
- 월 인프라 비용: **$0**

### 데이터 모델
- Firestore NoSQL: users/{userId}/todos, categories, searchHistory, reminders
