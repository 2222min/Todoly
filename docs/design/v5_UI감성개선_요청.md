---

## 현재 문제 분석

### 딱딱함의 원인
| 요소 | 현재 | 문제 |
|------|------|------|
| 배경색 | #FAF8F3 (차가운 회색빛 크림) | 따뜻함 부족 |
| 텍스트 | #1A1A1A (거의 순수 블랙) | 너무 강한 대비, 차가움 |
| 폰트 | Inter (기하학적, 직선적) | 딱딱한 인상 |
| 카드 | 흰색 + 얇은 그림자 | 평면적, 생기 없음 |
| 우선순위 색상 | #FF3B30 (iOS 시스템 레드) | 시스템 기본색, 개성 없음 |
| 전체 톤 | 무채색 위주 | 감성적 포인트 부재 |

---

## 개선 방향: "따뜻하고 아기자기한 감성"

| 요소 | 기존 | 변경 | 이유 |
|------|------|------|------|
| 배경 | #FAF8F3 | #FFF8F2 | 더 따뜻한 크림/피치 톤 |
| 텍스트 1차 | #1A1A1A | #2D2D2D | 약간 부드러운 다크 |
| 텍스트 2차 | #4B4B4B | #6B6B6B | 더 부드러운 그레이 |
| 우선순위 High | #FF3B30 | #FF6B6B | 부드러운 코랄 레드 |
| 우선순위 Med | #FF9500 | #FFAB5E | 부드러운 피치 오렌지 |
| 우선순위 Low | #007AFF | #5B9BF5 | 부드러운 스카이 블루 |
| 액센트 1 | 없음 | #FF8A65 | 코랄 (CTA, 포인트) |
| 액센트 2 | 없음 | #A78BFA | 라벤더 (카테고리 힌트) |
| 액센트 3 | 없음 | #6DD5C8 | 민트 (완료 표시) |

### 폰트 변경
| 요소 | 기존 | 변경 |
|------|------|------|
| 전체 | Inter | SF Pro Rounded (iOS 기본, 둥근 느낌) |
| 타이틀 | weight: .black | weight: .heavy, design: .rounded |
| 본문 | weight: .regular | weight: .medium, design: .rounded |

### 카드 스타일 변경
| 요소 | 기존 | 변경 |
|------|------|------|
| 배경 | 순백 #FFFFFF | 연한 피치 그라데이션 |
| 그림자 | 0.08 opacity, 8px | 0.06 opacity, 16px (더 부드럽고 넓게) |
| 코너 | 20px | 24px (더 둥글게) |
| 우선순위 바 | 4px 직선 | 4px + 상단 둥글게 |

### 인터랙션 감성
| 요소 | 기존 | 변경 |
|------|------|------|
| 화면 전환 | 기본 | spring 애니메이션 (탄성 있는 느낌) |
| 버튼 탭 | 없음 | 살짝 축소 후 복귀 (scaleEffect) |
| 카드 등장 | 없음 | 아래에서 위로 페이드인 |
| 스플래시 | 단순 페이드 | 회전 + 바운스 spring |

### 장식 요소
| 요소 | 설명 |
|------|------|
| 배경 원형 | 반투명 파스텔 원형 2~3개 (배경 장식) |
| 이모지 포인트 | 섹션 타이틀에 이모지 추가 |
| 그라데이션 | 헤더, CTA 버튼에 따뜻한 그라데이션 |
