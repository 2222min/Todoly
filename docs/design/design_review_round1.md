## 👤 시니어 디자이너 A (UI/비주얼 전문, 8년차)

### 1. Empty State
- ✅ 일러스트 + 메시지 + CTA 구성 좋음
- ✅ "Add First Task" 버튼 블랙 톤 — 브랜드 일관성 유지
- ⚠️ **Quick Add 섹션과 "Add First Task" 버튼이 기능 중복** → 빈 상태에서는 Quick Add 바를 숨기거나, "Add First Task" 버튼 탭 시 Quick Add 입력 필드에 포커스를 주는 방식으로 통합 검토
- ⚠️ **일러스트 사이즈가 화면 대비 너무 큼** (448x448) → 모바일 기준 280~320px 정도로 축소 권장. 현재 비율이면 스크롤 없이 CTA가 보이지 않을 수 있음

### 2. Trash
- ✅ 정보 배너 (30일 안내) 잘 배치됨
- ✅ Restore 버튼 명확
- ⚠️ **"Delete All" 버튼에 확인 다이얼로그 없음** → 실수 방지를 위해 "정말 삭제하시겠습니까?" 확인 필요 (기획안 Undo 정책과 일관성)
- 🔴 **개별 항목 영구 삭제 버튼 없음** → 기획안에는 "복원 / 영구 삭제 버튼" 둘 다 있어야 함. 현재 Restore만 존재

### 3. Main List
- ✅ Bento 카드 레이아웃 — 시각적으로 매력적
- ✅ 우선순위 컬러바 (좌측 border) 직관적
- ✅ OVERDUE/TODAY 배지 잘 보임
- ⚠️ **Header/TopAppBar가 Main List에 없음** → Empty State에는 "Todoly" 헤더 + 검색 + 햄버거 메뉴가 있는데, Main List에서는 바로 "Hello, Planner."로 시작. 네비게이션 일관성 필요
- ⚠️ **Bottom Navigation Bar가 Main List에 없음** → Empty State에는 하단 탭바가 있는데 Main List에는 없음. 통일 필요
- 🔴 **검색 기능 진입점 없음** → 기획안 핵심 기능인 검색바가 Main List에서 보이지 않음

### 4. Task Detail
- ✅ Bento Grid 메타데이터 레이아웃 세련됨
- ✅ 우선순위 칩 (High/Medium/Low) 컬러 구분 명확
- ✅ 카테고리 칩 + 추가 버튼(+) 좋음
- ⚠️ **"Visual Context: Project Focus" 이미지 영역** → 기획안에 없는 기능. 사용자가 이미지를 첨부하는 기능인지 명확하지 않음. 의도 확인 필요
- ⚠️ **Notes 영역이 너무 작음** → 멀티라인 입력인데 높이가 고정되어 보임. 자동 확장 또는 최소 높이 증가 필요

## 👤 시니어 디자이너 B (UX/인터랙션 전문, 7년차)

### 1. Empty State
- ✅ 감성적 메시지 ("Big things happen with small steps") 좋음
- ⚠️ **Bottom Nav 아이콘 의미 불명확** → 3개 아이콘이 있는데 라벨이 없음. 첫 사용자는 각 탭이 뭔지 모름 → 아이콘 하단에 텍스트 라벨 추가 필요 (List / Categories / Trash 등)
- ⚠️ **FAB(플로팅 버튼)과 "Add Task" 버튼과 "Add First Task" 버튼** → 할 일 추가 진입점이 3개. 인지 부하 발생. Empty State에서는 CTA 하나로 통일 권장

### 2. Trash
- ✅ 심플하고 명확한 구조
- ⚠️ **스와이프 삭제 어포던스 없음** → 항목을 스와이프하면 영구 삭제할 수 있다는 힌트가 없음. 첫 항목에 살짝 스와이프 힌트 애니메이션 또는 안내 텍스트 고려
- ⚠️ **하단 일러스트 + 메시지 영역** → 항목이 있는 상태에서 보여줄 필요가 있는지 의문. 항목이 0개일 때만 표시하는 게 더 깔끔

### 3. Main List
- ✅ "Hello, Planner." 인사말 — 개인화 느낌 좋음
- ✅ 미완료/완료 섹션 분리 잘 됨
- 🔴 **Bento 카드가 2열 그리드인데 모바일에서 가독성 이슈** → 카드 내 텍스트가 매우 작아질 수 있음. 모바일(375px 기준)에서 1열 리스트 또는 카드 높이 조정 필요
- ⚠️ **완료 항목의 삭제 아이콘(휴지통)이 너무 작음** → 터치 타겟 최소 44x44pt 확보 필요
- ⚠️ **"Show All" 버튼** → 완료 항목이 2개뿐인데 접혀있는 느낌. 기획안의 "접기/펼치기" 토글과 동작이 다를 수 있음. 명확한 인터랙션 정의 필요

### 4. Task Detail
- ✅ X(닫기) + Save 헤더 구성 직관적
- ⚠️ **마감일 입력 방식** → "04/28/2026" 텍스트 직접 입력 형태인데, Date Picker(캘린더) UI가 더 적합. 텍스트 탭 시 캘린더 팝업 연동 필요
- ⚠️ **Delete Task 버튼 위치** → 이미지 아래 하단에 있어 스크롤해야 보임. 헤더 우측 더보기(⋯) 메뉴 안에 넣거나, 스와이프 제스처로 대체 검토
- 🔴 **메모(Notes)와 마감일/우선순위가 같은 높이의 Bento Grid** → Notes는 내용이 길어질 수 있는데 오른쪽 칼럼과 높이가 맞춰져 있어 확장성 문제

## 👤 미들급 디자이너 C (4년차)

### 전체
- ⚠️ **폰트 일관성** → Empty State 타이틀은 Inter Black, Main List는 Inter Bold, Task Detail은 Inter Black. 타이틀 웨이트 통일 필요
- ⚠️ **라운딩 값 통일** → 카드 32px, 버튼 9999px(pill), 입력 필드 32px 등 혼재. 디자인 토큰으로 정리 필요 (예: card=24px, button=pill, input=16px)

### 개별 화면
- Empty State: ✅ 전체적으로 깔끔
- Trash: ⚠️ 삭제 날짜 텍스트 색상(#afafaf)이 배경 대비 명도 대비 부족 → 접근성(WCAG AA) 미달 가능성. 최소 4.5:1 대비 확보 필요
- Main List: ⚠️ 카드 내 메모 텍스트(#4b4b4b, 14px)가 작은 화면에서 읽기 어려울 수 있음
- Task Detail: ⚠️ 우선순위 "High" 버튼 배경색(#ba1a1a)과 "Medium" 텍스트색(#ff9500)이 기획안 색상(#FF3B30, #FF9500)과 다름 → 기획안 컬러 팔레트와 맞추기

## 👔 대표 리뷰

### 종합 평가
디자인 퀄리티가 높고 모던한 느낌이 잘 살아있습니다. 특히 Main List의 Bento 카드 레이아웃과 우선순위 컬러바는 기획 의도를 잘 반영했습니다.

다만, **기획안과의 정합성** 및 **화면 간 일관성**에서 수정이 필요합니다.

### 🔴 반드시 수정 (Critical)

| # | 화면 | 이슈 | 수정 방향 |
|---|------|------|----------|
| 1 | Main List | 헤더(Todoly + 검색 + 메뉴) 누락 | Empty State와 동일한 헤더 추가 |
| 2 | Main List | Bottom Nav Bar 누락 | Empty State와 동일한 하단 탭바 추가 |
| 3 | Main List | 검색 기능 진입점 없음 | 헤더에 검색 아이콘 포함 |
| 4 | Trash | 개별 영구 삭제 버튼 없음 | Restore 옆에 Delete 버튼 추가 또는 스와이프 삭제 |
| 5 | Main List | 모바일 2열 카드 가독성 | 모바일에서 카드 텍스트 크기/레이아웃 검증 |
| 6 | Task Detail | Notes 영역 확장성 | 자동 높이 확장 또는 최소 높이 증가 |
